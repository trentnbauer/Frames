# Tags and subjects

## Manage names

Settings → Tags & subjects has one searchable management modal for both types. Create, rename, merge within a type or delete names. Existing tags and subjects are not merged across types automatically.

## Provenance and photo details

AI tags show **✦** before the name; the separate × action removes a tag. The marker identifies AI-derived data rather than whether a tag is selected.

On a photo, **Colour & variants** opens its palette and actual linked photographs. Photoshoot Share controls are described in [Share links](Share-links).

See [Bulk metadata](Bulk-metadata) for adding tags or subjects to a selection.
