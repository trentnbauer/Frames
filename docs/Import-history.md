# Import history

**Import history.** Library and the upload completion dialog link to persistent per-file outcomes for new uploads and library scans. Transfer outcomes (staged/rejected) are separate from processing outcomes (ready, duplicate, removed, failed or unfinished). Downloaded cloud copies appear when scanned; provider transfer failures remain in Cloud sync settings. Retry unfinished processing without reimporting successful files, including after a restart. Rejected uploads must be uploaded again. The most recent 100 runs and first 2,000 files per run are shown. Camera/lens and analysis counts describe current imported metadata, not extra files to add to the total. Failed processing retries are bounded to 500 files per request. History starts with new runs; existing imports are not backfilled. Retained originals at removed paths are excluded from pending counts and later scan batches, and cloud sync leaves those removed copies unchanged. Use Recently removed to restore a photo deliberately; merely scanning does not restore it. Real cloud-provider reconnect/download failures were not tested against live accounts.
