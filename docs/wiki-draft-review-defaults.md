# Wiki draft: Review schedule defaults

For the *Review schedule* page, after the first paragraph:

**Default schedule.** A new library rates each photo in seven sessions, spaced Instant → 1 day → 3 days → 1 week → 1 week → 1 month → 6 months (Settings, Reviews, Schedule). A library that already had photographs before this default changed, and never chose its own spacing, keeps the earlier default: four sessions a week apart. Either can be changed at any time.
