# Library workflows

- [Bulk metadata](Bulk-metadata): preview, Fill blanks, resumable edits and Undo.
- [Recovery and Undo](Recovery-and-undo): recently removed photos, retention and safe restoration.
- [Saved Library views](Saved-library-views): named live filter definitions.

All workflow records are private to the signed-in person's library. Recovery and import history start with new removals/runs; existing deleted ratings cannot be reconstructed. See the [manual testing checklist](Testing-library-workflows).
